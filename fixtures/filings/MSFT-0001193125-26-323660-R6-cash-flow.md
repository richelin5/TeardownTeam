**Important:** Microsoft tags D&A as the company extension element `msft:DepreciationAmortizationAndOther` ("Depreciation, amortization, and other"), NOT a us-gaap element. Custom extensions are not in the SEC companyfacts API, so D&A (and therefore EBITDA) may be unavailable from standard tags for MSFT. Check companyfacts for any us-gaap D&A fallback before concluding "not reported". Never use the msft extension value silently.
