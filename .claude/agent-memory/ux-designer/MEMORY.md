## Known facts and decisions (seeded 2026-11-27 from the research docs)
- The page must fit one landscape US Letter page. Phone layout stacks sections, and tables scroll inside their containers.
- Banking color code: blue = hard-coded input (e.g. share price), black = calculated.
- Every number needs a source affordance (footnote marker + popover). In print, popovers become numbered endnotes.
- Required states: loading, not found, unsupported filer, partial data, rate-limited.
